A git graph (GitKraken-style)

The panel's branches view is a commit graph: each save is a dot on its branch's lane, and branch names are tags on their tip. Clicking a dot looks back at that version. The most "git" of the three, and the busiest.

C · save icon, git-style

The states, from least to most saved. Hovering any of them says the same thing in a sentence, and clicking opens Settings → Repo.
  1. Only in this browser: the local demo. Nothing leaves the tab (IndexedDB).
  2. On the server only: saved by atlas, not in git.
  3. In a repo, not pushed: committed on atlas's own repo, or ahead of the remote. Shows how many.
  4. Synced with the repo: the same as what's on the remote.
Plus two passing states: syncing and can't reach the repo.
